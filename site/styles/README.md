# Theme styles

The legacy files were copied from the local `static/css/` generated by
the legacy aoike-sycamore build. That ignored directory is NOT a build input
for Notist. This snapshot belongs in Git so clean checkouts and CI work without
running the Rust/Trunk build first.

- `main.scss`: the single SCSS entry point, importing the old theme and adding
  Notist-specific layout and interaction adapters. Compiled to `/main.css` by
  Notist's built-in Sass pipeline; browsers do not consume SCSS source.
- `_legacy.scss`, `_var.scss`, `elements/`: original SCSS source. `_legacy.scss`
  is the old `main.scss`, renamed as a partial to avoid a second CSS output.
- `uno.css`: frozen UnoCSS output, including preflight, utilities, icons and
  the `nav-btn` shortcut. This temporary setup does NOT regenerate UnoCSS or
  require Node packages. New utility names need a later generator integration.
- `tools/site_assets.py`: prepare extension publishes this `uno.css` through
  `target/site-static/css/uno.css`; Notist then collects it as an ordinary asset.

Load UnoCSS first, then the SCSS output, then Notist syntax highlighting.
Notist-specific layout, heading anchors, dialog lightbox and comment state
adapters remain in this directory's `main.scss`. Do not edit the original ignored
`static/css/` to change this theme, or regenerate this snapshot implicitly.

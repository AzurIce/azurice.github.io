# Waline 公开评论只读调查

时间：2026-11-06。服务：`https://waline.azurice.top`。

只进行了公开接口 GET 查询；未登录管理员、读取配置密钥、导出数据库或修改/提交评论。报告不保存评论正文、用户标识、昵称、邮箱、地址或其他个人数据。

## 查询与结果

`GET /api/comment?type=recent&count=10` 成功，仅返回 1 条公开记录，其 `url` 为 `/`。

逐页调用 `GET /api/comment?path=<路径>&pageSize=100&page=1` 均成功：

| 路径 | 公开接口 count |
| --- | ---: |
| `/` | 1 |
| `/posts/launchd-md` | 0 |
| `/posts/cpp-rtti-md` | 0 |
| `/posts/linux-kernel-module-typ` | 0 |
| `/posts/x86-64-minimum-linux-kernel-typ` | 0 |
| `/gallery` | 0 |

全局 recent 只发现首页这一条，是上述逐页结果的交叉验证，不是管理员数据库全量导出。管理员列表接口需要认证（HTTP 401），没有继续尝试访问。

## 判断与限制

- Waline 的评论记录以 `url` 关联页面；客户端 `path` 决定请求的页面身份。改文章地址且采用新 path，会让旧 path 下的评论不出现在新页面，而不是删除评论。
- 目前可见的唯一公开评论属于首页；保持首页 `/` 后，它不受文章 slug 变化影响。四篇旧文章路径没有发现公开评论，因此没有发现必须保留旧 slug 的公开评论数据依据。
- 无管理员权限，不能排除待审核、垃圾箱、隐藏记录，或公开接口未暴露的其它数据。如果要保证数据库里任何状态的评论都不受影响，需要用户在管理后台核对各记录的 URL，或提供只包含 URL / 状态 / 数量的脱敏导出。
- 调查是此刻的快照；正式切换前应复查，避免其间新增评论。文章 URL 变化对外部旧链接的影响独立存在，即使旧路径没有评论，也不代表旧链接会自动重定向。

## 样站决定

取消旧 slug 重映射，使用 Notist 默认文章 `.html` 地址。文章评论采用新页面路径，首页仍采用 `/`。没有改动 Waline 数据，也没有修改生产站点。
